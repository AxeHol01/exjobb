Some good things to know:

Pre-processing is run every time. This is not taken into account when counting the time it takes to train the model.

The dataset is too big to upload onto GitHub, so it has to be downloaded separately. Please put the files into the PQ_data folder. The dataset can be downloaded here: https://zenodo.org/records/14062900 

The paths in the code are hardcoded. Please edit them as appropriate.
